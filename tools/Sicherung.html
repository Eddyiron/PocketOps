PocketOps Sichern & Zurückholen Sicherungen, Ordner, Angst nehmen
Jedes Werkzeug hat oben rechts Speichern und Öffnen. Damit legst du deine Arbeit als Datei ab und holst sie wieder zurück. Mehr ist es nicht — und genau das ist die ganze Sicherung.

Erst einmal: Es kann nichts kaputtgehen

Die Datei, die beim Speichern entsteht, endet auf .json. Das klingt nach Technik, ist aber das Harmloseste, was es gibt: eine Textdatei. Du kannst sie mit dem Editor öffnen und lesen — da steht dein Text, deine Zahlen, deine Kärtchen. Kein Programm, kein Makro, nichts, was von allein etwas tut.

Sie lässt sich also gefahrlos kopieren, verschicken, auf ein Laufwerk legen oder doppelt ablegen. Geht beim Hin- und Herschieben einmal etwas schief, merkt das Werkzeug es beim Öffnen und sagt es — es passiert nichts Stilles.

Warum es sich lohnt

Solange du nur arbeitest, liegt alles im Browser. Das ist bequem: Du schließt das Fenster, öffnest es morgen wieder, und alles ist noch da.

Aber der Browser ist kein Safe. Räumt jemand die Browserdaten auf — du selbst, ein Hilfsprogramm, die IT-Abteilung —, dann ist der Stand weg. Dasselbe gilt für ein neues Gerät oder ein anderes Benutzerkonto. Die gespeicherte Datei überlebt das alles, weil sie ganz gewöhnlich auf deiner Festplatte liegt.

Und sie kann noch etwas: Sie ist der Weg von einem Rechner zum anderen. Zu Hause gespeichert, im Büro geöffnet — dieselbe Arbeit.

So gehst du am besten vor

Ein Ordner, darin ein Ordner je Werkzeug

Lege einmal einen Ordner an — dort, wo deine anderen Dateien auch liegen, etwa unter Dokumente. Darin bekommt jedes Werkzeug seinen eigenen Unterordner. Dann suchst du nie wieder, wohin etwas gehört:

Dokumente\PocketOps-Sicherungen\ ├─ Kanban\ │ 2026-10-04 Projekt Nord.json │ 2026-09-28 Projekt Nord.json ├─ Notizbuch\ │ 2026-10-01 Mein Notizbuch.json ├─ Diagramm\ │ 2026-10-04 Umsatz je Quartal.json └─ Tagesplan\ 2026-10-04 Woche 41.json

Das Datum nach vorn

Schreibe das Datum rückwärts an den Anfang: 2026-10-04, nicht 04.10.2026. Dann sortiert der Dateimanager von allein richtig, und die neueste Fassung steht immer unten. Dahinter ein Wort, das dir sagt, worum es geht.

Wann speichern?

  • Bevor du etwas Großes änderst — umräumen, löschen, neu sortieren. Dann hast du den Stand davor noch.
  • Wenn du fertig bist mit einer Sitzung, an der dir etwas liegt.
  • Einmal in der Woche für alles, woran du laufend arbeitest.

Die letzten drei behalten

Alte Sicherungen nicht überschreiben, sondern danebenlegen und ab und zu aufräumen. Drei Stände reichen fast immer. Der Nutzen: Merkst du erst nach zwei Tagen, dass etwas fehlt, hilft dir die Datei von gestern nichts — die von vorletzter Woche schon.

Den Ordner in die Wolke legen

Liegt der Sicherungsordner in OneDrive, Dropbox oder auf einem Netzlaufwerk, ist er nebenbei auch außer Haus gesichert und auf dem anderen Rechner da. Du musst dafür nichts einstellen — nur den Ordner an die richtige Stelle legen.

Zurückholen, Schritt für Schritt

  1. Das Werkzeug öffnen, um das es geht — eine Kanban-Datei gehört ins Kanban, eine Notizbuch-Datei ins Notizbuch.
  2. Oben rechts auf Öffnen klicken.
  3. Im Dateifenster deinen Ordner suchen und die gewünschte Datei wählen.
  4. Fertig. Der Stand aus der Datei ist da und ersetzt, was vorher im Fenster stand.

Vorsicht an genau dieser Stelle: Öffnen ersetzt den aktuellen Stand. Wenn du im Fenster gerade etwas hast, das du behalten willst, speichere es vorher — zwei Sekunden, und nichts kann mehr schiefgehen.

Was sichert welches Werkzeug?

Speichern / Öffnen Kanban, Kanban mit Bahnen, Notizbuch, Tagesplan, Mindmap, Whiteboard, Diagramm, Team-Radar, RACI-Matrix, Entscheidungsmatrix, Priorisierungsmatrix, Stakeholder-Karte, SlideCraft, Roadmap — eine JSON-Datei mit allem darin.
Eigenes Format Dokument gibt Word aus, SlideCraft zusätzlich PowerPoint, der Markdown-Editor eine MD-Datei, Diagramm ein PNG. Das sind fertige Ergebnisse zum Weitergeben — als Sicherung taugt die JSON-Datei besser, weil sich nur daraus wieder weiterarbeiten lässt.
Nur im Browser Timer, Rechner und die drei Spiele merken sich Kleinigkeiten, die niemand sichern muss. Beim Sprachmemo liegen die Aufnahmen im Browser — die lädst du einzeln herunter.

Häufige Sorgen

„Ich habe die Datei aus Versehen im Editor geöffnet und etwas getippt."

Nicht speichern, Editor schließen — dann ist nichts passiert. Hast du schon gespeichert, nimm die Fassung von vorher. Genau dafür behältst du drei.

„Kann ich die Datei jemandem schicken?"

Ja. Sie enthält genau das, was du im Werkzeug siehst — nicht mehr. Denk nur daran, dass auch alles mitgeht, was drinsteht: Namen, Zahlen, Notizen.

„Beim Öffnen kommt eine Meldung."

Dann passt die Datei nicht zu diesem Werkzeug, oder sie ist unterwegs beschädigt worden. Der vorherige Stand bleibt unangetastet stehen. Prüfe, ob du die richtige Datei erwischt hast.

„Muss ich etwas einrichten?"

Nein. Keine Anmeldung, kein Konto, keine Einstellung. Nur der Ordner, den du einmal anlegst.

Every tool has Save and Open at the top right. That is how you put your work into a file and bring it back. There is nothing more to it — and that is your whole backup.

First of all: nothing can break

The file you get when you save ends in .json. That sounds technical, but it is the most harmless thing there is: a text file. You can open it in any editor and read it — your text, your numbers, your cards are all in there. No program, no macro, nothing that does anything by itself.

So you can copy it, send it, put it on a drive or keep two of them, with no risk at all. If something does go wrong while it is being moved around, the tool notices when you open it and says so — nothing ever fails quietly.

Why it is worth doing

While you are simply working, everything sits in the browser. That is convenient: you close the window, open it again tomorrow, and it is all still there.

But a browser is not a safe. If anyone clears the browser data — you, a cleanup tool, the IT department — the work is gone. The same goes for a new device or a different user account. A saved file survives all of that, because it sits on your hard disk like any other file.

And it does one more thing: it is the way from one computer to another. Saved at home, opened at the office — the same work.

How best to go about it

One folder, with a folder per tool inside

Set up a folder once — wherever your other files live, say under Documents. Inside it, every tool gets a subfolder of its own. Then you never have to wonder where something belongs:

Documents\PocketOps-backups\ ├─ Kanban\ │ 2026-10-04 Project North.json │ 2026-09-28 Project North.json ├─ Notebook\ │ 2026-10-01 My notebook.json ├─ Chart\ │ 2026-10-04 Revenue per quarter.json └─ Day plan\ 2026-10-04 Week 41.json

Put the date first

Write the date backwards at the start: 2026-10-04, not 04/10/2026. Then the file manager sorts it correctly by itself and the newest version is always at the bottom. After the date, one word that tells you what it is about.

When to save

  • Before you change something big — rearranging, deleting, re-sorting. Then you still have the state from before.
  • When you have finished a session that matters to you.
  • Once a week for everything you work on continuously.

Keep the last three

Do not overwrite old backups; put the new one beside them and tidy up now and then. Three versions are almost always enough. Here is why: if you only notice two days later that something is missing, yesterday's file is no help — the one from two weeks ago is.

Put the folder in the cloud

If the backup folder lives in OneDrive, Dropbox or on a network drive, it is also kept off-site and is there on your other computer. There is nothing to set up — just put the folder in the right place.

Restoring, step by step

  1. Open the tool it belongs to — a Kanban file goes into Kanban, a notebook file into the Notebook.
  2. Click Open at the top right.
  3. Find your folder in the file dialog and pick the file you want.
  4. Done. What was in the file is now there, in place of whatever was in the window before.

Careful at exactly this point: opening replaces what is there now. If the window holds something you want to keep, save it first — two seconds, and nothing can go wrong.

What does each tool save?

Save / Open Kanban, Kanban with lanes, Notebook, Day plan, Mind map, Whiteboard, Chart, Team radar, RACI matrix, Decision matrix, Priority matrix, Stakeholder map, SlideCraft — one JSON file with everything in it.
Its own format Document produces Word, SlideCraft also PowerPoint, the Markdown editor an MD file, Chart a PNG. Those are finished results to pass on — as a backup the JSON file is better, because only from that can you carry on working.

Common worries

"I opened the file in an editor by accident and typed something."

Do not save, close the editor — then nothing has happened. If you did save, take the version from before. That is exactly why you keep three.

"Can I send the file to someone?"

Yes. It holds exactly what you see in the tool — no more. Just remember that everything in it travels along too: names, numbers, notes.

"I get a message when I open it."

Then the file does not belong to this tool, or it was damaged on the way. What was there before is left untouched. Check whether you picked the right file.

"Do I have to set anything up?"

No. No sign-in, no account, no settings. Just the folder you create once.
